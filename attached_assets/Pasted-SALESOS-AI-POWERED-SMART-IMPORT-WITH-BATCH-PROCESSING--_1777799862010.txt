## ARCHITECTURE

### PHASE 1: FILE UPLOAD & PARSING
=====================================

Endpoint: POST /api/import/ai-smart/preview

Input:
- multipart form-data
- file: any file (CSV, Excel, JSON, TXT)
- org_id: auto from auth

Process:
1. Read file bytes
2. Detect format (CSV → parse with csv-parser, Excel → xlsx, JSON → parse)
3. Extract first 10 rows (preview)
4. Send to Claude for analysis:

Claude prompt:
```
Analyze this raw data from a file. Extract all contacts and leads.

Data:
[raw_rows_json]

Return JSON with:
```

### PHASE 2: BATCH PROCESSING & WORKER TASKS
=============================================

If user clicks "Yes":

Endpoint: POST /api/import/ai-smart/execute

Input:
```
{
  file_id: "upload-123",
  org_id: "org-456",
  confirmed: true
}
```

Logic:

1. Check file size:
   - Small (< 1MB): Process as 1 batch
   - Medium (1-10MB): Split into 2-3 batches (500 rows per batch)
   - Large (> 10MB): Split into N batches

2. Create import job:
   ```
   INSERT INTO import_jobs (id, org_id, file_id, status, total_rows, batches)
   VALUES (job-123, org-456, upload-123, 'processing', 264, 1)
   ```

3. For each batch:
   - Create worker task: `POST /api/import/ai-smart/worker`
   - Worker processes batch with Claude
   - Worker inserts into DB
   - Update import_jobs: progress, status

4. Aggregate results when all batches done

**Worker Endpoint:**

```
POST /api/import/ai-smart/worker

Input:
{
  job_id: "job-123",
  batch_number: 1,
  batch_size: 200,
  file_id: "upload-123",
  rows: [...]
}

Process:
1. Send rows to Claude
2. Claude extracts/normalizes
3. Dedupe by email (case-insensitive)
4. Create contacts in DB:
   - Check: SELECT * FROM contacts WHERE lower(email) = lower(?)
   - If exists: update (merge)
   - If new: insert
5. Create leads if status present
6. Log warnings
7. Return: { imported: 200, leads: 35, warnings: [...] }

Update job progress:
UPDATE import_jobs
SET batch_{n}_status = 'done', batch_{n}_count = 200
WHERE id = job-123

When all batches done:
UPDATE import_jobs
SET status = 'completed', ended_at = now()
WHERE id = job-123
```

### PHASE 3: DATABASE SCHEMA
============================

New table: `import_jobs`

```sql
CREATE TABLE import_jobs (
  id UUID PRIMARY KEY,
  org_id UUID NOT NULL REFERENCES organizations(id),
  file_id VARCHAR(255),
  file_name VARCHAR(255),
  status VARCHAR(50), -- 'preview', 'processing', 'completed', 'failed'
  total_rows INT,
  total_batches INT,
  imported_contacts INT DEFAULT 0,
  imported_leads INT DEFAULT 0,
  errors INT DEFAULT 0,
  data_quality DECIMAL(3,2), -- 0.95
  preview_data JSONB, -- full preview from Claude
  batch_results JSONB, -- array of batch results
  error_log JSONB, -- array of errors
  started_at TIMESTAMP,
  ended_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

Add to existing tables:

contacts table:
- Add column: import_job_id UUID (link back to import job)
- Add column: data_quality DECIMAL(3,2) (per-contact confidence)

leads table:
- Add column: import_job_id UUID
```

```typescript
const [step, setStep] = useState('upload'); // upload → preview → processing → done

// Step 1: Upload
const handleFileSelect = async (file) => {
  setStep('preview');
  const res = await fetch('/api/import/ai-smart/preview', {
    method: 'POST',
    body: formData // file + org_id
  });
  const preview = await res.json();
  setPreview(preview);
};

// Step 2: Show preview
// User sees data quality, issues, sample contacts
// Clicks "Confirm Import"

// Step 3: Start processing
const handleConfirm = async () => {
  setStep('processing');
  const res = await fetch('/api/import/ai-smart/execute', {
    method: 'POST',
    body: JSON.stringify({ file_id, org_id, confirmed: true })
  });
  const job = await res.json();
  
  // Poll for progress
  const pollProgress = setInterval(() => {
    fetch(`/api/import/ai-smart/job/${job.id}`)
      .then(r => r.json())
      .then(data => {
        setProgress(data);
        if (data.status === 'completed') {
          clearInterval(pollProgress);
          setStep('done');
        }
      });
  }, 1000); // Check every 1 second
};

// Step 4: Show results
// Display summary, issues, import count
// Button: "Go to Contacts" or "Import Another File"
```

### PHASE 5: CLAUDE PROMPT ENGINEERING
======================================

**Main extraction prompt:**

```
You are a data import assistant. Your job is to analyze raw data and extract contacts and leads.

Raw data:
[raw_data_json_or_csv]

Rules:
1. Extract ALL contacts, even if some fields missing
2. Normalize field names (First Name + Last Name → name)
3. Standardize phone format (remove dashes, keep digits + country code)
4. Standardize email (lowercase, trim)
5. Detect duplicates by email (case-insensitive)
6. Handle multi-line addresses
7. Detect company from text
8. Detect contact title from "Job Title" or similar
9. Map lead status: "In Progress" → "negotiating", "New" → "new", etc.
10. Extract budget/deal amount as integer

Return JSON:
{
  "contacts": [
    {
      "name": "John Smith",
      "email": "john@acme.com",
      "phone": "+1-212-555-0147",
      "company": "Acme Corp",
      "title": "VP Sales",
      "confidence": 0.99
    }
  ],
  "leads": [
    {
      "contact_email": "john@acme.com",
      "company": "Acme Corp",
      "stage": "negotiating",
      "value_usd": 50000,
      "close_date": "2026-04-15",
      "confidence": 0.92
    }
  ],
  "deduplication": [
    { "email": "john@acme.com", "kept_index": 0, "removed_indices": [5, 12] }
  ],

    "Row 2: No email address (marked as note only)",
    "Row 5: Duplicate of row 1 (kept first, removed second)",
```
