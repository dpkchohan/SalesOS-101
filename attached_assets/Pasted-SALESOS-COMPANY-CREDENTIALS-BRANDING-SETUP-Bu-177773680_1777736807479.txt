SALESOS - COMPANY CREDENTIALS & BRANDING SETUP
==============================================

Build company branding management (1.5 hours).

This unlocks proposal generation next.

---

## OVERVIEW

Users need to store:
- Company name, logo, colors, footer text
- Website, phone, email, address, tax ID
- These get applied to all generated proposals automatically

Flow:
1. User goes to Settings → Company Profile
2. Uploads logo + fills form
3. Picks primary/secondary colors (color picker)
4. Saves
5. Sees live preview of how proposal will look
6. Claude uses this data when generating proposals

---

## PHASE 1: DATABASE SCHEMA
===========================

Create new table: `company_credentials`

```sql
CREATE TABLE company_credentials (
  id UUID PRIMARY KEY,
  org_id UUID NOT NULL UNIQUE REFERENCES organizations(id),
  company_name VARCHAR(255),
  company_logo_url VARCHAR(500), -- URL to uploaded logo
  primary_color VARCHAR(7), -- hex: #667eea
  secondary_color VARCHAR(7), -- hex: #764ba2
  accent_color VARCHAR(7), -- hex: #ff6b00
  footer_text TEXT, -- "Phenomeny LLP | AI Automation"
  website VARCHAR(255),
  phone VARCHAR(20),
  email VARCHAR(255),
  address TEXT,
  tax_id VARCHAR(50), -- GST ID, etc
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

Run: `pnpm --filter @workspace/db run push`

## PHASE 2: BACKEND API ENDPOINTS
=================================

File: `artifacts/api-server/src/routes/companyCredentials.ts`

**Endpoints:**

```
GET /api/company-credentials
- Authenticated (Clerk auth required)
- Return: company_credentials for user's org
- If not found: return 404 or null

POST /api/company-credentials
- Create or update credentials
- Input: { company_name, primary_color, secondary_color, ... }
- Return: created/updated record

POST /api/company-credentials/logo
- Upload logo file
- Accept: JPG, PNG (max 2MB)
- Upload to URL storage (Google Drive or AWS S3)
- Return: { logo_url: "https://..." }
- Save URL in company_credentials

GET /api/company-credentials/preview
- Return branding data for preview
- Used by frontend to show sample proposal
```

**Implementation:**

```typescript
// GET
router.get('/company-credentials', authenticateUser, async (req, res) => {
  const orgId = req.user.orgId;
  
  const creds = await db
    .select()
    .from(companyCredentialsTable)
    .where(eq(companyCredentialsTable.orgId, orgId))
    .limit(1);
  
  if (!creds.length) {
    return res.status(404).json({ error: 'No company credentials found' });
  }
  
  res.json(creds[0]);
});

// POST (create/update)
router.post('/company-credentials', authenticateUser, async (req, res) => {
  const orgId = req.user.orgId;
  const { company_name, primary_color, secondary_color, ... } = req.body;
  
  // Validate colors (hex format)
  if (!isValidHex(primary_color)) {
    return res.status(400).json({ error: 'Invalid color format' });
  }
  
  const existing = await db
    .select()
    .from(companyCredentialsTable)
    .where(eq(companyCredentialsTable.orgId, orgId))
    .limit(1);
  
  if (existing.length) {
    // Update
    const updated = await db
      .update(companyCredentialsTable)
      .set({ ... })
      .where(eq(companyCredentialsTable.orgId, orgId))
      .returning();
    
    return res.json(updated[0]);
  } else {
    // Create
    const created = await db
      .insert(companyCredentialsTable)
      .values({ org_id: orgId, ... })
      .returning();
    
    return res.json(created[0]);
  }
});

// POST logo upload
router.post('/company-credentials/logo', authenticateUser, async (req, res) => {
  const file = req.files?.logo;
  
  if (!file) {
    return res.status(400).json({ error: 'No file provided' });
  }
  
  if (file.size > 2 * 1024 * 1024) { // 2MB max
    return res.status(413).json({ error: 'File too large (max 2MB)' });
  }
  
  // Upload to Google Drive or AWS S3
  const logoUrl = await uploadFile(file);
  
  // Save URL to DB
  const orgId = req.user.orgId;
  const updated = await db
    .update(companyCredentialsTable)
    .set({ company_logo_url: logoUrl, updated_at: new Date() })
    .where(eq(companyCredentialsTable.orgId, orgId))
    .returning();
  
  res.json({ logo_url: logoUrl });
});
```

// artifacts/salesos-web/src/pages/Settings.tsx

import { useState, useEffect } from 'react';
import { useAuth } from '@clerk/react';

export default function Settings() {
  const { getToken } = useAuth();
  
  const [formData, setFormData] = useState({
    company_name: '',
    primary_color: '#667eea',
    secondary_color: '#764ba2',
    accent_color: '#ff6b00',
    footer_text: '',
    website: '',
    phone: '',
    email: '',
    address: '',
    tax_id: ''
  });
  
  const [loading, setLoading] = useState(false);
  const [saved, setSaved] = useState(false);
  const [logoFile, setLogoFile] = useState(null);
  const [logoUrl, setLogoUrl] = useState('');
  const [showPreview, setShowPreview] = useState(false);

  // Load existing credentials
  useEffect(() => {
    loadCredentials();
  }, []);

  const loadCredentials = async () => {
    const token = await getToken();
    const res = await fetch('/api/company-credentials', {
      headers: { Authorization: `Bearer ${token}` }
    });
    
    if (res.ok) {
      const data = await res.json();
      setFormData(data);
      setLogoUrl(data.company_logo_url);
    }
  };

  const handleInputChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({ ...prev, [name]: value }));
  };

  const handleColorChange = (field, value) => {
    setFormData(prev => ({ ...prev, [field]: value }));
  };

  const handleLogoUpload = async (e) => {
    const file = e.target.files[0];
    if (!file) return;

    const formData = new FormData();
    formData.append('logo', file);

    const token = await getToken();
    const res = await fetch('/api/company-credentials/logo', {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}` },
      body: formData
    });

    if (res.ok) {
      const data = await res.json();
      setLogoUrl(data.logo_url);
      setSaved(true);
      setTimeout(() => setSaved(false), 2000);
    }
  };

  const handleSave = async () => {
    setLoading(true);
    const token = await getToken();
    
    const res = await fetch('/api/company-credentials', {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${token}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(formData)
    });

    setLoading(false);
    if (res.ok) {
      setSaved(true);
      setTimeout(() => setSaved(false), 2000);
    }
  };

  return (
    <div className="p-8 max-w-2xl">
      <h1 className="text-3xl font-bold mb-8">Settings</h1>

      <div className="space-y-6">
        {/* Company Name */}
        <div>
          <label className="block text-sm font-medium mb-2">Company Name</label>
          <input
            type="text"
            name="company_name"
            value={formData.company_name}
            onChange={handleInputChange}
            className="w-full px-4 py-2 border rounded-lg"
            placeholder="Phenomeny LLP"
          />
        </div>

        {/* Logo Upload */}
        <div>
          <label className="block text-sm font-medium mb-2">Company Logo</label>
          <div className="flex items-center gap-4">
            <div className="w-24 h-24 bg-gray-100 rounded-lg flex items-center justify-center">
              {logoUrl ? (
                <img src={logoUrl} alt="Logo" className="max-w-full max-h-full" />
              ) : (
                <span className="text-gray-400">No logo</span>
              )}
            </div>
            <input
              type="file"
              accept="image/jpeg,image/png"
              onChange={handleLogoUpload}
              className="px-4 py-2 border rounded-lg"
            />
          </div>
        </div>

        {/* Colors */}
        <div className="grid grid-cols-3 gap-4">
          <div>
            <label className="block text-sm font-medium mb-2">Primary Color</label>
            <input
              type="color"
              value={formData.primary_color}
              onChange={(e) => handleColorChange('primary_color', e.target.value)}
              className="w-full h-10 rounded-lg cursor-pointer"
            />
          </div>
          <div>
            <label className="block text-sm font-medium mb-2">Secondary Color</label>
            <input
              type="color"
              value={formData.secondary_color}
              onChange={(e) => handleColorChange('secondary_color', e.target.value)}
              className="w-full h-10 rounded-lg cursor-pointer"
            />
          </div>
          <div>
            <label className="block text-sm font-medium mb-2">Accent Color</label>
            <input
              type="color"
              value={formData.accent_color}
              onChange={(e) => handleColorChange('accent_color', e.target.value)}
              className="w-full h-10 rounded-lg cursor-pointer"
            />
          </div>
        </div>

        {/* Footer Text */}
        <div>
          <label className="block text-sm font-medium mb-2">Footer Text</label>
          <textarea
            name="footer_text"
            value={formData.footer_text}
            onChange={handleInputChange}
            className="w-full px-4 py-2 border rounded-lg"
            placeholder="Phenomeny LLP | AI Automation for Sales Teams"
            rows="3"
          />
        </div>

        {/* Contact Info */}
        <div className="grid grid-cols-2 gap-4">
          <div>
            <label className="block text-sm font-medium mb-2">Website</label>
            <input
              type="text"
              name="website"
              value={formData.website}
              onChange={handleInputChange}
              className="w-full px-4 py-2 border rounded-lg"
              placeholder="https://phenomeny.in"
            />
          </div>
          <div>
            <label className="block text-sm font-medium mb-2">Phone</label>
            <input
              type="text"
              name="phone"
              value={formData.phone}
              onChange={handleInputChange}
              className="w-full px-4 py-2 border rounded-lg"
              placeholder="+91-99903-77727"
            />
          </div>
          <div>
            <label className="block text-sm font-medium mb-2">Email</label>
            <input
              type="email"
              name="email"
              value={formData.email}
              onChange={handleInputChange}
              className="w-full px-4 py-2 border rounded-lg"
              placeholder="deepak@pddt.in"
            />
          </div>
          <div>
            <label className="block text-sm font-medium mb-2">Tax ID</label>
            <input
              type="text"
              name="tax_id"
              value={formData.tax_id}
              onChange={handleInputChange}
              className="w-full px-4 py-2 border rounded-lg"
              placeholder="GST ID"
            />
          </div>
        </div>

        {/* Address */}
        <div>
          <label className="block text-sm font-medium mb-2">Address</label>
          <textarea
            name="address"
            value={formData.address}
            onChange={handleInputChange}
            className="w-full px-4 py-2 border rounded-lg"
            placeholder="123 Main Street, Delhi, India"
            rows="3"
          />
        </div>

        {/* Buttons */}
        <div className="flex gap-4">
          <button
            onClick={handleSave}
            disabled={loading}
            className="px-6 py-2 bg-orange-600 text-white rounded-lg hover:bg-orange-700 disabled:opacity-50"
          >
            {loading ? 'Saving...' : 'Save'}
          </button>
          <button
            onClick={() => setShowPreview(!showPreview)}
            className="px-6 py-2 border rounded-lg hover:bg-gray-50"
          >
            {showPreview ? 'Hide Preview' : 'Preview'}
          </button>
          {saved && <span className="text-green-600">✓ Saved</span>}
        </div>
      </div>

      {/* Preview Section */}
      {showPreview && (
        <div className="mt-12 pt-12 border-t">
          <h2 className="text-2xl font-bold mb-6">Proposal Preview</h2>
          <ProposalPreview branding={formData} logo={logoUrl} />
        </div>
      )}
    </div>
  );
}
