## DATABASE SCHEMA

### Update contacts table

Add columns:
```sql
ALTER TABLE contacts ADD COLUMN (
  customer_no VARCHAR(20) UNIQUE, -- "CUST-000001", "CUST-000002", etc
  is_duplicate BOOLEAN DEFAULT false, -- flagged as potential duplicate
  duplicate_of UUID REFERENCES contacts(id), -- link to original if merged
  merged_at TIMESTAMP, -- when merged
  merged_reason VARCHAR(255) -- "Duplicate email: john@acme.com",
  phone_normalized VARCHAR(20), -- standardized phone for matching
  email_normalized VARCHAR(255), -- lowercase for matching
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Indexes for duplicate detection
CREATE INDEX idx_contacts_email_normalized ON contacts(org_id, email_normalized);
CREATE INDEX idx_contacts_phone_normalized ON contacts(org_id, phone_normalized);
```

## CUSTOMER NUMBER GENERATION

**Format:** CUST-XXXXXX (6 digits, auto-incrementing per org)

Example:
- CUST-000001 (first contact in org)
- CUST-000002 (second contact)
- CUST-000265 (265th contact)

**Implementation:**

```typescript
// Generate unique customer number

const generateCustomerNo = async (orgId: string) => {
  const lastContact = await db
    .select()
    .from(contactsTable)
    .where(eq(contactsTable.orgId, orgId))
    .orderBy(desc(contactsTable.createdAt))
    .limit(1);
  
  let nextNo = 1;
  if (lastContact.length > 0 && lastContact[0].customerNo) {
    const lastNo = parseInt(lastContact[0].customerNo.split('-')[1]);
    nextNo = lastNo + 1;
  }
  
  return `CUST-${String(nextNo).padStart(6, '0')}`;
};

// On contact creation:
const customerNo = await generateCustomerNo(orgId);
await db.insert(contactsTable).values({
  ...contactData,
  customerNo,
  emailNormalized: contactData.email?.toLowerCase() || null,
  phoneNormalized: normalizePhone(contactData.phone)
});
```

**Normalize Functions:**

```typescript
// Normalize phone: remove dashes, spaces, parens
const normalizePhone = (phone: string): string => {
  if (!phone) return null;
  return phone.replace(/[\s\-\(\)]/g, '');
};

// Email normalization: lowercase only
const normalizeEmail = (email: string): string => {
  if (!email) return null;
  return email.toLowerCase().trim();
};
```

## DUPLICATE DETECTION

### Algorithm

On contact creation OR import:

```
1. If email provided:
   - Normalize email (lowercase)
   - Query: SELECT * FROM contacts WHERE email_normalized = normalized_email
   - If match found: FLAG AS DUPLICATE

2. If phone provided:
   - Normalize phone (remove special chars)
   - Query: SELECT * FROM contacts WHERE phone_normalized = normalized_phone
   - If match found: FLAG AS DUPLICATE

3. Mark contact:
   - is_duplicate = true
   - Store which existing contact it matches (duplicate_of)
   - Store reason: "Duplicate email: john@acme.com" or "Duplicate phone: +1-212-555-0147"

4. Show to user:
   - Chat: "⚠️ Duplicate detected. John Smith (CUST-000001) has same email.
            [Merge] [Keep Both] [Replace]"
   - Or in UI: flag in contact list with badge "DUPLICATE"
```

**Backend Endpoint:**

```
POST /api/contacts/create (or /api/contacts/import)

Input:
{
  name: "John Smith",
  email: "john@acme.com",
  phone: "+1-212-555-0147",
  company: "Acme Corp"
}

Process:
1. Normalize email + phone
2. Check duplicates:
   - duplicate_email = db.select where email_normalized = ?
   - duplicate_phone = db.select where phone_normalized = ?
3. If duplicate found:
   - Return: { 
       "duplicate_detected": true,
       "existing_contact": { id, customerNo, name, email, phone },
       "action_required": "merge | keep_both | replace"
     }
4. If no duplicate:
   - Create contact
   - Return: { success: true, customer_no: "CUST-000001" }
```

## MERGE FUNCTIONALITY

**Endpoint: POST /api/contacts/merge**

Input:
```
{
  keep_id: "contact-001", // which contact to keep
  merge_id: "contact-265", // which to merge into keep_id
  merge_strategy: "keep_both_fields" // or "use_keep_only"
}
```

Process:
```
1. Keep original contact (CUST-000001)
2. Merge fields:
   - For each field in merge_contact:
     - If keep_contact.field is empty: use merge_contact.field
     - If both have values: ask user which to keep
3. Move all interactions from merge_contact to keep_contact
4. Move all leads from merge_contact to keep_contact
5. Mark merge_contact as deleted:
   - is_duplicate = true
   - duplicate_of = keep_contact.id
   - merged_at = now()
   - merged_reason = "Merged with CUST-000001"
6. Keep customer number for keep_contact (CUST-000001)
7. Mark old number as inactive

Response:
{
  "success": true,
  "kept_contact_id": "contact-001",
  "kept_customer_no": "CUST-000001",
  "merged_customer_no": "CUST-000265",
  "interactions_moved": 12,
  "leads_moved": 3
}
```

## DUPLICATE DETECTION RULES

### Email Match (HIGH CONFIDENCE)
```
john@acme.com = john@acme.com (after normalization)
→ FLAG AS DUPLICATE: 100% confidence
```

### Phone Match (HIGH CONFIDENCE)
```
+1-212-555-0147 = 2125550147 (after normalization)
→ FLAG AS DUPLICATE: 100% confidence
```

### Fuzzy Match (MEDIUM CONFIDENCE) - Optional
```
(For future enhancement)
"John Smith" ≈ "Jon Smith" → 85% confidence
"Sarah Jones" ≈ "Sara Jones" → 90% confidence
→ FLAG AS POSSIBLE DUPLICATE: Manual review recommended
```

## API ENDPOINTS

```
POST /api/contacts
- Create contact
- Auto-detect duplicates
- Return: { success, duplicate_detected?, existing_contact? }

GET /api/contacts/duplicates
- List all flagged duplicates in org
- Return: [ { id, customerNo, email, phone, duplicate_of, reason } ]

POST /api/contacts/merge
- Merge two contacts
- Keep one, merge other
- Move interactions + leads
- Return: { success, kept_id, merged_id }

GET /api/contacts/:id/related
- Get potential duplicate contacts
- Return: [ { id, customerNo, email, phone, similarity_score } ]

POST /api/contacts/deduplicate
- Run bulk deduplication on org
- Check all contacts for duplicates
- Return: { duplicates_found, merged, remaining }
```
