5. API Endpoints
Create artifacts/api-server/src/routes/storage.ts:
POST /api/storage/upload

Body: { filename: string, contentType: string, fileSize: number, folder: string }

Validation: Check quota before returning URL
Returns: { uploadUrl: string, fileKey: string, expiresIn: number }
Update storage_usage by incrementing used_bytes

GET /api/storage/download/*

Route uses wildcard to capture full file key with slashes
Extract file key from req.params[0]
Auth: Required
Verify org_id matches the fileKey prefix (security check)
Returns: { downloadUrl: string, expiresIn: number }

Route uses wildcard to capture full file key with slashes
Extract file key from req.params[0]
Auth: Required
Verify org_id ownership

Returns: { success: true }

GET /api/storage/usage

Auth: Required
Returns: { usedBytes: number, quotaBytes: number, usedMB: number, quotaMB: number, percentUsed: number }

Register routes in artifacts/api-server/src/app.ts.
