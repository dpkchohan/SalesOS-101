### TASK 2: PROPOSAL GENERATION WORKFLOW (2 hrs)

What: User says "Send John a proposal" → Claude generates → user approves → email sent

Build:

**Backend:**

Endpoint: POST /api/documents/generate-proposal

Input:
```
{
  contact_id: "123",
  lead_id: "456",
  context: "Discussed pricing, timeline, features"
}
```

Logic:
1. Fetch contact + lead + all interactions (full context)
2. Fetch company_credentials (branding)
3. Send to Claude:
   - Company branding (logo, colors, footer)
   - Contact info (name, company, email, phone)
   - Lead context (stage, budget, timeline)
   - Recent interactions (what was discussed)
4. Claude generates HTML proposal with:
   - Logo at top (company_logo_url)
   - Headings in primary_color
   - Section buttons in secondary_color
   - Footer text at bottom
5. Save to documents table:
   - type: "proposal"
   - content: HTML
   - status: "draft"
   - contact_id, lead_id
6. Return: { document_id, title, content }

Endpoint: POST /api/documents/:id/approve-and-send

Input:
```
{
  document_id: "doc-123",
  email_to: "john@acme.com",
  subject: "Your Proposal"
}
```

Logic:
1. Fetch document (HTML)
2. Convert HTML to PDF (use @react-pdf/renderer or similar)
3. Generate email body with Claude:
   - AI writes personalized email
   - References proposal
   - Mentions next steps
4. Send via email:
   - POST to Gmail API (use existing integration)
   - Attach PDF
   - Log in emails table
5. Update document:
   - status: "sent"
   - sent_at: now()
6. Return: { success: true, email_sent: true }

**Frontend:**

Chat command: "Send [contact] a proposal about [context]"

Chat.tsx enhancement:
- Claude detects: intent="send_proposal", contact_id, context
- Backend: POST /api/documents/generate-proposal
- Show: "Generating proposal..."
- Receive HTML from backend
- Show: ProposalPreview component (full proposal in modal)

Buttons on preview:
- [Request Changes] → textarea for feedback → re-generate
- [Approve & Send] → click → modal for email preview

Email preview modal:
- Show AI-generated email subject + body
- Buttons: [Edit Email] [Send]
- On Send: POST /api/documents/:id/approve-and-send

After send:
- Chat: "✓ Proposal sent to john@acme.com"
- Document detail page shows "Sent" status

**Frontend Pages:**

/documents/:id - Document detail view
- Show full proposal
- Status badge (Draft/Sent/Approved)
- Created/Sent timestamps
- Buttons: [Edit] [Share] [Send Again] [Download PDF]

Buttons:
