## PHASE 4: CHAT ENGINE - INTENT DETECTION (2 days)
===================================================

**What:**
- Create `/api/chat` endpoint
- Claude API integration to understand user intent
- Parse commands: "Add John from TCS", "Move lead to negotiating", "Log call with Sarah"

**Tech Stack:**
- Claude API (@anthropic-ai/sdk)
- Prompt engineering for intent detection

**Workflow:**
```
User: "Add John from TCS, $50k budget, Q2 close"
  ↓
POST /api/chat (send text)
  ↓
Claude parses intent + entities
  ↓
Returns: { intent: "create_lead", contact_name: "John", company: "TCS", budget: 50000, close_date: "Q2" }
  ↓
Backend executes (create contact + lead)
  ↓
Response: { success: true, lead_id: "123", message: "John from TCS added" }
```

**Output:**
- `/api/chat` endpoint accepts user text
- Claude parses and returns structured JSON
- Backend executes action based on intent
- Frontend displays result

**Done Criteria:**
- [ ] Chat endpoint working
- [ ] Claude correctly parses 5+ intents (add contact, create lead, log interaction, move lead, create task)
- [ ] Entities extracted correctly (names, emails, budgets, dates)
- [ ] Actions execute in DB

## PHASE 7: RED FLAGS / AI SIGNALS (2 days)
===========================================

**What:**
- Claude analyzes leads for red flags
- Creates AI signal records automatically
- Shows on dashboard + lead detail

**Tech Stack:**
- Claude API (analysis)
- Drizzle insert into ai_signals table

**Red Flags to Detect:**
- Deal stalling (no contact > 5 days)
- Budget unconfirmed
- Timeline vague
- Long in one stage (> 20 days)

**Workflow:**
```
Endpoint: POST /api/leads/:id/analyze
  ↓
Claude reads lead + interaction history
  ↓
Claude detects: "Deal stalling. No contact in 7 days."
  ↓
Creates ai_signal record
  ↓
Returns signal to frontend
  ↓
Dashboard shows red flags
```

**Output:**
- Leads auto-analyzed for risks
- AI signals stored and displayed
- Real-time alerts on dashboard

**Done Criteria:**
- [ ] `/api/leads/:id/analyze` working
- [ ] Claude detects all 4+ red flag types
- [ ] Signals persisted to DB
- [ ] Dashboard shows active signals
- [ ] Lead detail shows relevant signals
