Add Company Credentials & Branding Management.

Current issue:
- No way to store company branding
- AI doesn't know logo, colors, company name for proposals
- No company profile page

Build this:

STEP 1: Database - Company Settings Table
Create: company_credentials table

Fields:
- id UUID
- org_id UUID (link to organization)
- company_name VARCHAR
- company_logo_url VARCHAR (URL to uploaded logo)
- primary_color VARCHAR (hex: #667eea)
- secondary_color VARCHAR (hex #764ba2)
- footer_text VARCHAR (e.g., "Phenomeny LLP | AI Automation for Sales Teams")
- website VARCHAR
- phone VARCHAR
- email VARCHAR
- address VARCHAR
- tax_id VARCHAR (GST/Tax ID)
- created_at TIMESTAMP
- updated_at TIMESTAMP

STEP 2: Company Profile Page
Frontend: /settings/company

Show form with fields:
- Company Name
- Logo Upload (drag-drop image)
- Primary Color (color picker)
- Secondary Color (color picker)
- Footer Text
- Website
- Phone
- Email
- Address
- Tax ID

Buttons: [Save] [Cancel] [Preview]

When click Preview:
- Show how proposal will look with these colors/logo/footer

STEP 3: First-Time Setup Prompt
On first document generation:

If company_credentials don't exist:
- Show modal: "Set up your company branding"
- Show form (same as company profile)
- Required fields: Company Name, Logo, Colors, Footer
- Button: [Continue to Proposal]
- After submit, generate proposal with these credentials

STEP 4: AI Access Credentials
When generating proposal: POST /api/documents/generate

Backend:
1. Fetch company_credentials from DB (WHERE org_id = user.org_id)
2. Pass to Claude:
   {
     company_name: "Phenomeny LLP",
     logo_url: "https://...",
     primary_color: "#667eea",
     secondary_color: "#764ba2",
     footer_text: "Phenomeny LLP | AI Automation for Sales Teams",
     website: "https://phenomeny.in",
     phone: "+91-99903-77727",
     email: "deepak@pddt.in"
   }

3. Claude generates HTML proposal with:
   - Logo at top (img src=logo_url)
   - Headings in primary_color
   - Buttons in secondary_color
   - Footer text at bottom
   - Website/phone/email in footer

STEP 5: Logo Upload Handler
Endpoint: POST /api/upload/logo

Input: multipart form-data (file + org_id)

Process:
- Accept: JPG, PNG (max 2MB)
- Upload to Google Drive or AWS S3
- Return: { logo_url: "https://..." }
- Save URL in company_credentials

STEP 6: Branding Preview
When user edits company profile:
- Show live preview of proposal template
- Show how logo + colors look
- Update preview as they change values
