SALESOS - BUSINESS CARD OCR + CHAT ATTACHMENTS
==============================================

Upload business cards, documents, and files directly in chat.
Claude extracts data (vision + document reading).
Ultra-minimal, zero-learning-curve UI.

Build time: 2-3 hours

---

## FEATURES

### 1. BUSINESS CARD EXTRACTION (Vision)
User: Takes photo of business card
  ↓
Uploads image in chat
  ↓
Claude reads image (vision API)
  ↓
Extracts: name, email, phone, company, title
  ↓
Adds to contacts automatically
  ↓
Chat shows: "✓ Added John Smith from Acme Corp"

### 2. DOCUMENT ATTACHMENTS (Multiple Formats)
User: Drag-drop PDF, PPT, Word, Excel, Text
  ↓
Claude reads document
  ↓
Claude summarizes or extracts data
  ↓
Chat shows summary + extracted data

### 3. IMAGE ATTACHMENTS
User: Upload JPG, PNG, WebP
  ↓
Claude analyzes image
  ↓
Describes content or extracts text
  ↓
Chat shows analysis

### 4. MINIMAL UI
No buttons. No complexity.
Just: Chat input → attachment button (paperclip) → drag or click

## DATABASE SCHEMA

New table: `chat_attachments`

```sql
CREATE TABLE chat_attachments (
  id UUID PRIMARY KEY,
  org_id UUID NOT NULL REFERENCES organizations(id),
  message_id UUID REFERENCES messages(id),
  file_name VARCHAR(255),
  file_type VARCHAR(50), -- 'image', 'pdf', 'docx', 'pptx', 'xlsx', 'txt'
  file_url VARCHAR(500), -- stored in cloud
  file_size INT,
  mime_type VARCHAR(100),
  extracted_data JSONB, -- what Claude extracted
  extraction_status VARCHAR(50), -- 'pending', 'processing', 'done', 'failed'
  created_at TIMESTAMP DEFAULT NOW()
);

Add to messages table:
- attachment_ids UUID[] (array of attachment IDs)
- has_attachment BOOLEAN DEFAULT false
```

## BACKEND - ATTACHMENT HANDLING

### Endpoint 1: Upload Attachment

```
POST /api/attachments/upload

Input:
- multipart/form-data
- file (image, PDF, Word, PPT, Excel, Text)
- org_id (auto from auth)

Validation:
- Max 10MB per file
- Allowed types: jpg, png, pdf, docx, xlsx, pptx, txt, webp
- Reject: exe, sh, bat, etc.

Process:
1. Upload to cloud storage (Google Drive or AWS S3)
2. Create attachment record in DB (status: pending)
3. Return: { attachment_id, file_url, status: 'pending' }

Response:
{
  "id": "att-123",
  "file_name": "business_card.jpg",
  "file_url": "https://...",
  "status": "pending"
}
```

### Endpoint 2: Trigger Extraction

```
POST /api/attachments/:id/extract

Process (based on file type):

1. IMAGE (JPG, PNG, WebP):
   - Send to Claude vision API
   - Prompt: "Extract all contact info from this business card:
     name, email, phone, company, title, website, address"
   - Claude returns structured JSON
   - Check if contact already exists (by email)
   - Auto-add to contacts if confirmed by user

2. PDF:
   - Extract text using pdfparse library
   - Send to Claude: "Extract all contact/lead info from this PDF"
   - Return: structured data

3. DOCX (Word):
   - Extract text using mammoth library
   - Send to Claude: "Analyze this document. Extract any business cards, 
     contact lists, or lead information"
   - Return: structured data

4. PPTX (PowerPoint):
   - Extract text from slides
   - Send to Claude: "Analyze these slides. Extract contact info, 
     company names, deal info, pricing"
   - Return: structured data

5. XLSX (Excel):
   - Parse as table/CSV
   - Send to Claude: "Analyze this spreadsheet. Map columns intelligently.
     Extract all contacts and leads"
   - Return: structured data

6. TXT (Plain Text):
   - Read raw text
   - Send to Claude: "Extract all contact/lead information from this text"
   - Return: structured data

Response to Chat:
- Show what was extracted
- Show confidence score
- Show preview
- Button: [Add to Contacts] [Add as Lead] [Dismiss]
```

### Claude Prompts (by file type)

**Business Card Image:**
```
You are a business card reader. Extract the following from this image:
- Full name (first + last)
- Email address
- Phone number
- Company name
- Job title
- Website
- Physical address
- LinkedIn profile (if visible)

Return valid JSON only (no markdown):
{
  "name": "John Smith",
  "email": "john@acme.com",
  "phone": "+1-212-555-0147",
  "company": "Acme Corporation",
  "title": "VP Sales",
  "website": "https://acme.com",
  "address": "123 Main St, New York, NY 10001",
  "linkedin": "linkedin.com/in/johnsmith",
  "confidence": 0.98
}

If you can't extract a field, leave it null. Be strict - only extract what you clearly see.
```

**PDF Document:**
```
Analyze this PDF document. Extract all business cards, contact lists, or lead information.

Return JSON:
{
  "document_type": "invoice | contract | contact_list | proposal | other",
  "contacts": [
    { "name": "...", "email": "...", "phone": "...", "company": "..." }
  ],
  "leads": [
    { "contact_name": "...", "company": "...", "stage": "...", "budget": ... }
  ],
  "summary": "One sentence describing the document",
  "extraction_confidence": 0.95
}
```

**Excel/CSV:**
```
Analyze this spreadsheet. Intelligently map columns. Extract all contacts and leads.

Return JSON:
{
  "contacts": [...],
  "leads": [...],
  "column_mapping": { "A": "name", "B": "email", ... },
  "data_quality": 0.92
}
```

**PowerPoint:**
```
Analyze these slides. Extract contact info, company names, deal info, pricing, leads.

Return JSON:
{
  "slide_count": 10,
  "contacts": [...],

## CLAUDE VISION API (Business Cards)

```typescript
// For image attachments (business cards)

import Anthropic from "@anthropic-ai/sdk";
import fs from "fs";

const client = new Anthropic();

const extractFromCard = async (imageUrl) => {
  const response = await client.messages.create({
    model: "claude-3-5-sonnet-20241022",
    max_tokens: 1024,
    messages: [
      {
        role: "user",
        content: [
          {
            type: "image",
            source: {
              type: "url",
              url: imageUrl
            }
          },
          {
            type: "text",
            text: `You are a business card reader. Extract the following from this image:
- Full name (first + last)
- Email address
- Phone number
- Company name
- Job title
- Website
- Physical address

Return valid JSON only (no markdown):
{
  "name": "...",
  "email": "...",
  "phone": "...",
  "company": "...",
  "title": "...",
  "website": "...",
  "address": "...",
  "confidence": 0.95
}

If you can't extract a field, set it to null.`
          }
        ]
      }
    ]
  });

  return JSON.parse(response.content[0].text);
};
```

## EDGE CASES HANDLED

```
✓ User uploads file with no extractable data
  → Claude: "Could not find contact info in this image"
  → Show error gracefully

✓ User uploads huge PDF (20MB)
  → Limit to 10MB
  → Show: "File too large (max 10MB)"

✓ User uploads unsupported format (.exe, .zip)
  → Reject: "File type not supported"

✓ User uploads business card, email already exists
  → Merge: "John Smith already exists. Merge contact info?"
  → Buttons: [Merge] [Create New]

✓ Claude extraction confidence < 50%
  → Show: "Low confidence. Please review:"
  → Show all fields
  → Allow user to edit before saving

✓ Document has multiple contacts
  → Claude extracts all
  → Show list: "[1] John Smith [2] Sarah Jones [3] Mike Brown"
  → User can add all or select specific ones
```
