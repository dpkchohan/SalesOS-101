## TASK 2: FIX VOICE INPUT - WHISPER TRANSCRIPTION (CRITICAL BUG)
===============================================================

**Problem:**
- User clicks record button
- Says something
- Nothing happens
- Getting 502 errors on /api/voice/transcribe

**Diagnosis:**

```
1. Check /api/voice/transcribe endpoint exists
   - Is it receiving audio file?
   - Is WHISPER_API_KEY set in .env?
   - Call Whisper API working?

2. Test endpoint directly:
   POST /api/voice/transcribe
   With audio file
   
3. Check logs:
   - What's the actual error?
   - Is Whisper API responding?
   - Is audio format correct (WAV/MP3)?

4. Frontend:
   - Recording button working?
   - Sending audio to API?
   - Getting 502 response?
```

**Fix:**

Backend: `/api/voice/transcribe`
```
1. Accept audio file (multipart form-data)
2. Check file size (max 25MB)
3. Call Whisper API:
   - POST to https://api.openai.com/v1/audio/transcriptions
   - Headers: Authorization: Bearer {WHISPER_API_KEY}
   - Language: 'en' or 'hi' for Hinglish
4. Return: { text: "transcribed text" }
5. Error handling:
   - If Whisper fails: return 502 with message
   - If file too large: return 413
   - If no audio: return 400
```

Frontend: Chat.tsx
```
1. Record button → capture audio
2. Stop recording → send to /api/voice/transcribe
3. Get text back
4. Add to chat input
5. User can edit or send
```

**Done when:**
- [ ] Click record button
- [ ] Speak into microphone
- [ ] Stop recording
- [ ] Text appears in chat
- [ ] No 502 errors
- [ ] Works with English and Hinglish

- Agent always speaks
- User can't disable for meetings/quiet places

**Build:**

Frontend: Chat.tsx

```
1. Add state: const [ttsEnabled, setTtsEnabled] = useState(true)

2. Add button in Chat header:
   Button: {ttsEnabled ? "🔊 Mute" : "🔇 Unmute"}
   onClick: setTtsEnabled(!ttsEnabled)

3. In playTts() function:
   if (ttsEnabled) {
     // Play audio
     const audio = new Audio(audioUrl)
     audio.play()
   } else {
     // Skip audio, just show text
   }

4. Persist preference:
   useEffect(() => {
     localStorage.setItem('ttsEnabled', ttsEnabled)
   }, [ttsEnabled])
   
   On load:
   const saved = localStorage.getItem('ttsEnabled')
   setTtsEnabled(saved !== 'false')

5. Visual indicator:
   Show icon change: 🔊 → 🔇
   Tooltip: "Agent TTS muted"
```
